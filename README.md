# Progetto – Analisi delle vendite in una catena di negozi

## Descrizione
Il progetto sviluppa un programma Python per analizzare i dati di vendita di una catena di negozi di elettronica.

Il programma utilizza:
- **NumPy** per le elaborazioni numeriche e le statistiche descrittive.
- **Pandas** per la gestione e l'analisi dei dati.
- **Matplotlib** per la creazione di grafici.

## Contenuto del progetto
- `progetto_vendite.py`: codice completo del progetto.
- `vendite.csv`: dataset iniziale generato automaticamente dal programma.
- `vendite_analizzate.csv`: dataset aggiornato con gli incassi e le categorie dei prodotti, generato al termine delle elaborazioni.

## Requisiti
È necessario avere Python installato e le seguenti librerie:

```bash
pip install numpy pandas matplotlib
```

## Esecuzione
Per avviare il programma:

```bash
python progetto_vendite.py
```

## Analisi realizzate
Il progetto comprende:
1. Creazione di un dataset con 40 vendite simulate.
2. Importazione e analisi dei dati con Pandas.
3. Calcolo degli incassi e dei prodotti più venduti.
4. Elaborazioni statistiche con NumPy.
5. Visualizzazione dei risultati con Matplotlib.
6. Analisi delle vendite per categoria.
7. Classifica dei prodotti in base all'incasso totale e grafico combinato.
